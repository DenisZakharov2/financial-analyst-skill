# Дизайн отчётов и графиков

Требования к визуальным материалам. Если пользователь не задал свой стиль,
используются значения ниже. Генератор `scripts/finanalyst/reporting.py` и
`scripts/finanalyst/visuals.py` следует палитре, шрифтам и сетке; размер маркеров
и выравнивание чисел зависят от формата (DOCX, PDF, XLSX, PPTX, HTML).

## Палитра

| Роль | Цвет |
|---|---|
| Основной текст, заголовки | `#1f2937` |
| Вторичный текст | `#374151` |
| Приглушённый текст | `#6b7280` |
| Линии и сетка | `#e5e7eb` |
| Фон карточек | `#ffffff` |
| Фон страницы | `#f8f9fa` |
| Положительное значение | `#10b981` |
| Отрицательное, тревога | `#ef4444` |
| Предупреждение | `#f59e0b` |
| Нейтральные данные | `#3b82f6` |

Градиенты — только для тепловых карт. Радужные градиенты на линейных графиках
запрещены. Контраст текста и фона — не ниже 4.5:1.

## Типографика

- Шрифт без засечек: Segoe UI, Roboto, Helvetica Neue, Arial; для PDF — DejaVu Sans.
- Заголовок отчёта 24–28 pt, разделы 16–18 pt, подписи 10–12 pt, таблицы 9–10 pt.
- Текст по левому краю, числа в таблицах — по правому.
- Разряды разделяются пробелом, десятичный разделитель — запятая.

## Графики

- Линия 2–3 pt, маркеры 6–8 pt, сетка светло-серая с прозрачностью 0.3.
- Столбцы без 3D и объёма, с отступом между категориями.
- Тепловые карты: последовательная палитра, контрастный текст в ячейках.
- Подпись оси X — под углом 45° для длинных меток; ось Y с единицей измерения.
- Заголовок графика описывает вывод, а не имя переменной.
- Легенда справа или снизу, не перекрывает данные.
- Пустой график не вставляется в отчёт: лучше пропуск, чем пустая рамка.

## Таблицы

- Заголовок с фоном `#f3f4f6`, жирный шрифт, граница по нижнему краю.
- Чередование строк `#f9fafb`.
- Числа по правому краю, 1–2 знака после запятой, разделитель тысяч — пробел.
- Ключевые значения выделяются жирным, а не только цветом.

## Презентация

- Титульный слайд: название, дата, автор, одно предложение о содержании.
- При числе слайдов больше четырёх — слайд «Содержание».
- Один слайд — одна мысль, не больше 6–8 строк.
- Нумерация слайдов обязательна.
- График занимает не менее 60 % площади, под ним — вывод одной строкой.
- Каждый слайд отвечает на вопрос «что это значит для бизнеса».

## HTML-дашборд

- Фильтры подписаны; рядом с неочевидным — иконка с подсказкой.
- Адаптивность: от 1024 px и на смартфоне в вертикальной ориентации.
- Наведение показывает точные значения, выбор фильтра перестраивает графики.
- Индикатор загрузки при инициализации.
- Никаких внешних CDN: Plotly встраивается в файл.
- Цвет не единственный носитель смысла: добавляйте подписи и паттерны.
