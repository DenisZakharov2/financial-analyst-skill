# Когорты: определение, окно, цензурирование

Когорта — группа клиентов с общим событием старта. Без явного определения
retention и LTV несопоставимы между отчётами.

## 1. Что считать стартом

Выберите одно и зафиксируйте в отчёте:

| Вариант | Когда подходит | Риск |
|---|---|---|
| Месяц регистрации клиента | Продукт один, регистрация = вход | Регистрация без продукта завышает базу |
| Месяц первого продукта | Портфель из нескольких продуктов | Нужна история всех продуктов |
| Месяц первой сделки | Продажи и конверсия | Пропускает клиентов без сделки |
| Месяц первого дохода | Юнит-экономика | Задерживает когорту на период активации |

По умолчанию: **месяц первого продукта**. Если его нет — месяц регистрации
с пометкой в допущениях.

## 2. Окно активности

```
Активен в месяце t = есть хотя бы одна операция или ненулевой остаток
```

Окно выбирается до расчёта: 30 дней, календарный месяц, квартал. Смешивать
окна в одном отчёте нельзя.

## 3. Retention по когорте

```
Retention(k, t) = активные из когорты k в месяце t / размер когорты k × 100
```

где `t` — номер месяца от старта когорты. Для t = 0 retention = 100 %.

```
Churn(k, t) = 1 − Retention(k, t)
```

`1 − Churn` верно для одного периода без реактивации. Если клиент может
вернуться, считайте отдельно возвраты и не называйте метрику «retention».

## 4. Цензурирование

Когорта, у которой прошло меньше `T` месяцев, не может показать retention
на горизонте `T`. Два варианта:

1. **Исключить неполные когорты** из средних — консервативно.
2. **Показать с пометкой** «данные неполные» — для мониторинга.

В отчёте указывайте, какой вариант выбран. Среднее по когортам с разным
горизонтом — классическая ошибка, занижающая ранний retention.

## 5. LTV по когортам

```
LTV_когорты(T) = Σ_{t=0..T} (выручка когорты в t / размер когорты) × маржинальность
```

Сравнивать когорты можно только на одинаковом `T`. Для прогноза LTV
экстраполируйте кривую удержания, а не средний чек.

## 6. Минимальный код

```python
import pandas as pd

# 1. Старт когорты: месяц первого продукта
first = (portfolio.groupby("client_id")["open_date"].min()
         .rename("first_date").reset_index())
first["cohort"] = pd.to_datetime(first["first_date"]).dt.to_period("M")

# 2. Активность по месяцам
activity = (transactions.assign(month=pd.to_datetime(transactions.txn_date).dt.to_period("M"))
            .merge(first[["client_id", "cohort"]], on="client_id")
            .assign(age=lambda d: (d["month"] - d["cohort"]).apply(lambda x: x.n))
            .groupby(["cohort", "age"])["client_id"].nunique().reset_index())

# 3. Retention
sizes = first.groupby("cohort")["client_id"].nunique()
activity["retention_pct"] = activity.apply(
    lambda row: row["client_id"] / sizes[row["cohort"]] * 100, axis=1)
```

## 7. Частые ошибки

- Когорта по календарному месяцу, а активность по 30-дневному окну — числа несопоставимы.
- Средний retention по всем когортам без учёта горизонта.
- LTV на когорте из 12 клиентов без доверительного интервала.
- Клиент, оформивший второй продукт, попадает в новую когорту — двойной счёт.
- Реактивация считается удержанием.
