# Языковые правила

Отчёт пишется по-русски. Правила проверяются функцией `lint_text`
(`scripts/finanalyst/reporting.py`) и вручную перед отправкой.

## 1. Один язык в предложении

Нельзя смешивать алфавиты внутри слова и вставлять английские слова вместо
русских эквивалентов. Аббревиатуры — можно, см. список ниже.

Плохо: русское слово с латинской буквой внутри; английское слово вместо
русского термина; слитное написание числа и слова.

Хорошо: «Кредитные карты сконцентрированы в массовом сегменте»,
«100 % указывают на рост», «расчёт по финансовым данным».

## 2. Разрешённая латиница

Только общепринятые термины: LTV, CAC, CPL, ARPU, ARPA, NIM, ROA, ROE, PAR,
NPL, DPD, ECL, KPI, YoY, QoQ, MoM, TAT, CAGR, ROI, ROMI, COGS, churn,
retention, TOFU, MOFU, BOFU, ABC, IQR, MAPE, MAE, RMSE, ARIMA, ETS, CSV,
Excel, JSON, PDF, DOCX, XLSX, PPTX, RTF, HTML, Python, SQL, API, ID, K-means,
Z-score, B2B, B2C, GitHub, MIT.

Всё остальное — по-русски или с расшифровкой в скобках при первом упоминании.

## 3. Опечатки и имена

Проверяйте названия продуктов, отделов, регионов, даты и формулы. Числа в тексте
сверяются с `metrics.json`, а не набираются вручную.

## 4. Символы

Допустимы кириллица, латиница в терминах, цифры, знаки препинания и
типографские символы: × — → − ≥ «» …

Недопустимы иероглифы и знаки других алфавитов, битые кодировки, нестандартные
кавычки. Неправильное склонение месяца — тоже ошибка: «провал в январе»,
а не «январь-провал».

## 5. Единицы измерения

У каждой суммы — валюта, у ставки — «% годовых», у срока — месяцы или дни,
у конверсии — «%». Без единицы число не выводится.

## 6. Читаемость

Короткие предложения, один термин — одно значение на протяжении всего отчёта.
Если термин вводится, он расшифровывается один раз.

## Как проверить

```bash
python - <<'PY'
from pathlib import Path
import sys
sys.path.insert(0, "skills/financial-analyst/scripts")
from finanalyst.reporting import lint_text
issues = lint_text(Path("report.md").read_text(encoding="utf-8"))
print("\n".join(issues) or "OK")
PY
```

Линтер ловит смешение алфавитов, двойные пробелы, латиницу вне списка
и пробелы в конце строк. Смысловые ошибки он не находит — их проверяет человек.
