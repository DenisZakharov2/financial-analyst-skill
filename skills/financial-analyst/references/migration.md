# Migration matrices и Vintage analysis: соглашения

## 1. Migration matrix (матрица переходов PAR-бакетов)

### Назначение
Показывает, как меняется распределение портфеля по PAR-бакетам между двумя срезами (базовым и целевым). Используется для оценки качества портфеля и эффективности работ с просрочкой.

### PAR-бакеты (по умолчанию)
```
current   — dpd < 30
30+       — 30 ≤ dpd < 60
60+       — 60 ≤ dpd < 90
90+       — dpd ≥ 90
```

Порядок бакетов фиксирован: current → 30+ → 60+ → 90+. Нельзя менять порядок или добавлять бакеты без обновления контракта метрик.

### Методология
1. **Ключ перехода** — `client_id`. Если у клиента несколько счетов, он назначается в **худший** (по порядку выше) бакет среди своих счетов в каждом срезе.
2. **Значения матрицы** — доля клиентов (или баланса) в процентах.
   - Режим `clients` (по умолчанию): уникальные клиенты, вес = 1.
   - Режим `balance`: сумма балансов клиента, вес = баланс в базовом срезе.
3. **Нормализация** — по строкам (базовый срез). Сумма по строке = 100 % (или 0 % для пустых строк).
4. **Закрытые счета** — исключаются из целевого среза, если `close_date ≤ snapshot_date`.

### Краевые случаи (metric-contracts.md)
| Ситуация | Обработка |
|---|---|
| Пустой базовый или целевой срез | Предупреждение, возвращается нулевая матрица 4×4 |
| Клиент есть в базовом, нет в целевом | Не попадает в матрицу (churn фиксируется в Bridge) |
| Клиент есть в целевом, не было в базовом | Не попадает в матрицу (new business в Bridge) |
| `balance = 0` в mode=balance | Вес 0, строка даёт 0 % |
| Отсутствующие колонки `dpd`, `balance`, `client_id` | Предупреждение, подставляется 0 / NaN |

### Формат отчёта
Строки = бакеты базового среза, столбцы = бакеты целевого среза.
Диагональ = клиенты, оставшиеся в том же бакете.
Выше диагонали = улучшение (курирование).
Ниже диагонали = ухудшение (ролл-рейт).

## 2. Vintage analysis (винтажный анализ)

### Назначение
Анализ качества портфеля по месяцам открытия счетов (винтажам). Позволяет выявлять «плохие» месяцы выдачи, динамику качества новых vintages и планировать резервы.

### Определение винтажа
**Винтаж = календарный месяц `open_date`** (YYYY-MM).
Если `open_date` отсутствует — счёт не попадает в анализ (предупреждение).

### Активность на дату среза (`as_of`)
Счёт считается **активным**, если:
- `open_date ≤ as_of`
- `balance > 0`
- `close_date > as_of` ИЛИ `close_date` отсутствует

По умолчанию `as_of = max(open_date)` в портфеле (дата последней выгрузки).

### Метрики по винтажу
| Метрика | Формула | Источник |
|---|---|---|
| `accounts` | `count(account_id)` | portfolio |
| `clients` | `nunique(client_id)` | portfolio |
| `balance` | `sum(balance)` | portfolio |
| `par30_pct` | `sum(balance where dpd≥30) / sum(balance) × 100` | portfolio.dpd, balance |
| `par60_pct` | `sum(balance where dpd≥60) / sum(balance) × 100` | portfolio.dpd, balance |
| `par90_pct` | `sum(balance where dpd≥90) / sum(balance) × 100` | portfolio.dpd, balance |
| `active_rate` | `count(active accounts) / accounts × 100` | portfolio |

### Краевые случаи (metric-contracts.md)
| Ситуация | Обработка |
|---|---|
| Пустой портфель | Предупреждение, пустой DataFrame |
| Нет колонки `open_date` | Предупреждение, пустой DataFrame |
| `balance = 0` для винтажа | `parXX_pct = null` (не 0) |
| Нет `dpd` | Предупреждение, `dpd = 0` |
| Нет `client_id` | Предупреждение, `clients = NaN` |
| Винтаж без активных счетов | `balance = 0`, `parXX_pct = null`, `active_rate = 0` |

### Цензурирование
Свежие винтажи (близкие к `as_of`) имеют короткий срок наблюдения. В отчёте указывается `as_of`. Для сравнения vintages используйте одинаковый горизонт (months on book).

## 3. CLI-флаги

| Флаг | Описание | Зависимости |
|---|---|---|
| `--migration` | Матрица переходов PAR-бакетов | `--compare-dirs` (оба среза) |
| `--migration-mode` | `clients` (умолч.) или `balance` | `--migration` |
| `--vintage` | Винтажный анализ | — (работает на текущем срезе) |

### Примеры
```bash
# Миграция между двумя срезами (по клиентам)
finanalyst --data-dir base --compare-dirs base target --migration

# Миграция по балансу
finanalyst --data-dir base --compare-dirs base target --migration --migration-mode balance

# Винтажный анализ на текущем срезе
finanalyst --data-dir sample --vintage
```
