# Пример данных

Небольшая синтетическая выгрузка, на которой скилл запускается за несколько секунд.
Все совпадения с реальными клиентами случайны.

| Файл | Строк | Что внутри |
|---|---|---|
| `clients.csv` | 60 | Клиенты, сегменты, каналы, даты регистрации |
| `products.csv` | 4 | Кредитная карта, кредит, вклад, страхование |
| `portfolio.csv` | 120 | Счета с остатками и просрочкой |
| `sales.csv` | 200 | Заявки: одна строка = максимальный этап |
| `funnel_events.csv` | 716 | События по каждому этапу с `application_id` |
| `finance.csv` | 24 | Выручка и расходы за 6 месяцев по 4 продуктам |

В `funnel_events` есть `application_id` — это позволяет посчитать честную
воронку по заявкам, а не по клиентам. В `finance` есть `marketing_cost`,
поэтому CAC и LTV считаются.

```bash
python scripts/analyze.py --data-dir assets/sample --out /tmp/fa --strict
```
