# Шаблон постановки задачи

Скопируйте и заполните. Угловые скобки — обязательные поля.

```text
Используй скилл financial-analyst.

Данные: <путь к каталогу>
Основные файлы: <portfolio.csv, finance.csv, ...>
Период: <с ... по ...>
Продукт: <...>
Разрезы: <регион, канал, сегмент>

Задача:
1. <что посчитать>
2. <какие сравнения нужны>
3. <какие аномалии искать>

Формат результата: <сводка / отчёт / таблица / дашборд / презентация>
Файлы: <DOCX / PDF / XLSX / PPTX / HTML>
Глубина: <экспресс / полный анализ>
Прогноз: <нет / горизонт, периодов>

Ограничения:
- <что нельзя показывать>
- <какие допущения уже согласованы>
- <срок>

Проверь данные на качество до расчёта и покажи, каких полей не хватает.
Если метрика не считается — скажи почему, не подставляй ноль.
```
